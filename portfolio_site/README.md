# Personal Portfolio Website

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server.

## Customize before publishing
- Check your name and introduction in `index.html`.
- Replace `your.email@example.com` with your real email.
- Replace the LinkedIn and GitHub URLs with your profile links.
- Put your CV PDF in this folder and name it `resume.pdf` (or update the link).
- Edit project descriptions and tags so they accurately reflect your work.
- Add links to your repositories where appropriate.

## Deploy with GitHub Pages
1. Create a GitHub repository and upload `index.html`, `style.css`, and `script.js`.
2. Open the repository's Settings -> Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the `main` branch and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish your site.
